# Master playbook

Rules that apply to every project unless the user says otherwise. The chief of staff starts each new project's playbook from here, and adds rules only with the user's approval.

**Version:** 1.0  **Last changed:** 2026-10-30

| ID | Rule (MUST / SHOULD) | Why | Source | Status |
|----|----------------------|-----|--------|--------|
| MPB-1 | Agents MUST interview the user one question at a time, and get the summary confirmed, before starting any new project | Builds start from what the user actually wants | User, 2026-10-30 | Approved |
| MPB-2 | Security MUST be built in from design onwards: no committed secrets, least privilege, validated input, fail closed | Security-first team | User, 2026-10-30 | Approved |
| MPB-3 | Everything user-facing MUST meet WCAG 2.2 AA as a minimum | Accessibility is non-negotiable | User, 2026-10-30 | Approved |
| MPB-4 | Content MUST be in plain UK English (GOV.UK style), with no em dashes or other AI writing tells | Clear, human writing | User, 2026-10-30 | Approved |
| MPB-5 | Designs MUST avoid generic "AI slop" looks and SHOULD offer A/B options for the user to choose from | Distinctive, user-centred design | User, 2026-10-30 | Approved |
| MPB-6 | Code MUST be the smallest complete change, reusing what exists before writing anything new | Less code, less risk | User, 2026-10-30 | Approved |
| MPB-7 | Pushing, merging, deploying, publishing, spending and accepting risk MUST have the user's explicit approval | The user owns high-impact decisions | User, 2026-10-30 | Approved |
| MPB-8 | Agents MUST check their work against the proof of done before reporting a task as complete | Agents are accountable for quality | User, 2026-10-30 | Approved |
| MPB-9 | Reports MUST be transparent: what worked, what didn't, what can be improved and how, in plain English | Anyone can understand the state of the work | User, 2026-10-30 | Approved |
| MPB-10 | Token use SHOULD be proportionate to the value of the task, without cutting safeguards | Get the most from each session | User, 2026-10-30 | Approved |
